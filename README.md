#Como testei

Comecei os testes de forma exploratória, ou seja, sem seguir um roteiro fixo de casos de teste desde o início. Comecei pela tela de login, e a partir daí fui testando as funcionalidades uma por uma, seguindo a ordem que elas aparecem na tela, da esquerda pra direita.

A ideia foi navegar pelo sistema como um usuário real faria, prestando atenção em cada botão, campo e fluxo, pra identificar comportamentos estranhos, erros ou coisas que não fizessem sentido. Sempre que encontrava algo fora do esperado, eu documentava o que aconteceu e registrava como um bug, junto com print ou vídeo mostrando o problema.

Escolhi essa abordagem porque, numa primeira rodada de testes, ela ajuda a conhecer melhor a aplicação e encontrar problemas que talvez passassem despercebidos se eu já tivesse seguido só uma lista fixa de casos de teste.

#Sugestão de melhoria
Faria uma revisão de critérios de aceite, de ux com o stakeholder da página, além de uma revisão funcional das funcionalidades
